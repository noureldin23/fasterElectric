Voglio creare un'applicazione web professionale chiamata "Faster Manager" per la gestione completa dei dipendenti e dei documenti aziendali.

OBIETTIVO

Realizzare un gestionale web moderno, responsive e professionale, utilizzabile da PC, tablet e smartphone.

L'applicazione sarà utilizzata dalla mia azienda per gestire circa 60 dipendenti e migliaia di documenti.

TECNOLOGIE RICHIESTE

Frontend:

* React
* TypeScript
* Tailwind CSS
* Interfaccia moderna e professionale

Backend:

* Node.js
* Express.js

Database:

* MySQL

Storage file:

* I documenti devono essere salvati sul server in cartelle organizzate
* Nel database devono essere salvati solo i percorsi dei file

Autenticazione:

* JWT
* Password criptate con bcrypt
